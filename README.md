## 🌱 Семя

Публичный GitHub-репозиторий с названием, адресом и клиентской сборкой сервера. Один репозиторий — один сервер.

Скачайте `template.zip` из релиза, перенесите всё содержимое в свой репозиторий и заполните `anthub.json`. GitHub Actions проверит файлы и опубликует сборку. Сайт и вручную созданные ключи не нужны.

## 🛠️ Установка

### Игроку

1. Установите Java **21**, Minecraft **1.21.1** и NeoForge **21.1.250**.
2. Поместите JAR AntHub из [релиза](https://github.com/abrosdaniel/anthub/releases/latest) в `mods` и запустите игру.
3. Нажмите **AntHub**, добавьте ссылку на семя или выберите проект из каталога.
4. Выберите компоненты, установите сборку и перезапустите игру, если появится запрос.
5. Нажмите **«Подключиться»**. На сервере меню открывается командой `/ah` и кнопка F8 по умолчанию.

### Владельцу сервера

1. Поместите JAR AntHub в `mods` сервера.
2. Запустите сервер, AntHub создаст нужные файлы, но не даст запустить сервер без настройки.
3. Создайте PostgreSQL и пользователя по инструкции ниже.
4. Откройте `config/anthub-server.toml`, заполните подключение и нужные разделы.
5. При необходимости установите моды интеграций и включите LuckPerms в конфиге.
6. Запустите сервер. Для всех новых функций используйте актуальную версию AntHub на обеих сторонах.

<a id="postgresql"></a>

### PostgreSQL

Создайте базу `anthub`. Под администратором PostgreSQL подключитесь к ней через `psql` и выполните **один раз**:

```sql
CREATE ROLE anthub LOGIN NOSUPERUSER NOCREATEDB NOCREATEROLE NOREPLICATION;
\password anthub
GRANT CONNECT ON DATABASE anthub TO anthub;
CREATE SCHEMA anthub AUTHORIZATION anthub;
```

`\password` запросит новый пароль дважды. Отдельный пользователь ограничивает доступ мода его схемой. При обновлении базу и пользователя пересоздавать не нужно.

В полном серверном конфиге заполните раздел:

```toml
[database]
host = "ИМЯ_ХОСТА"
port = "ПОРТ_ХОСТА"
database = "anthub"
username = "anthub"
password = 'ПАРОЛЬ_ПОЛЬЗОВАТЕЛЯ'
passwordEnvironment = ""
poolSize = 8
sslMode = "disable"
sslRootCert = ""
```

Пароль в TOML — **в кавычках**. Вместо `password` можно указать `passwordEnvironment = "ANTHUB_DB_PASSWORD"` и задать эту переменную процессу Minecraft. Если имя переменной заполнено, пароль берётся только из неё.

**Docker:** используйте Internal Host и порт Internal Port; контейнер Minecraft должен иметь доступ к сети базы. Публиковать порт БД в интернет не требуется. `sslMode = "disable"` подходит для доверенной внутренней сети; для внешнего подключения используйте `"verify-full"` и сертификат в `sslRootCert`.

> [!IMPORTANT]
> PostgreSQL нужна и при выключенном Auth. При ошибке подключения сервер остановит запуск с объяснением в консоли. Данные AntHub хранятся в БД отдельно от мира.

<a id="settings"></a>

## ⚙️ Настройки сервера

Все настройки — в `config/anthub-server.toml`. Применяются после полного перезапуска. Используйте **полный шаблон**: пропущенные, неизвестные или неверные параметры останавливают запуск.

| Раздел                      | Что настраивает                                                                             |
| :-------------------------- | :------------------------------------------------------------------------------------------ |
| `[project]`                 | `repository` — ссылка на семя; `requireProjectPack` — требовать AntHub и актуальную сборку. |
| `[connection]`              | `handshakeTimeoutSeconds` — время ответа клиента.                                           |
| `[integrations]`            | `luckperms = true` — права, префиксы и суффиксы из LuckPerms.                               |
| `[auth]`                    | Способ входа, регистрация и минимальная длина нового пароля.                                |
| `[database]`                | Подключение к PostgreSQL.                                                                   |
| `[skins]`                   | Скины игроков: включение, размер PNG, количество и источник обычного скина.                 |
| `[statistics]`              | Сбор и показ даты первого входа, активности, времени игры, сессии и смертей.                |
| `[moderationVotes]`         | Голосования о наказаниях: включение, длительность, допуск и паузы.                          |
| `[moderationVotes.actions]` | Разрешённые меры: `kick`, `ban`, `mute`.                                                    |
| `[community]`               | Разделы меню, категории, типы и лимит объединений.                                          |
| `[menu]`                    | Текст помощи и ссылки сервера.                                                              |
| `[updates]`                 | `notifyConsole` — WARN о новой версии при запуске и раз в 6 часов.                          |

Допустимые значения и диапазоны указаны в комментариях конфига. Выключение поля статистики останавливает его сбор и скрывает его, но сохраняет историю.

### Голосования о нарушениях

По умолчанию выключены. Инициатор выбирает игрока, причину, меру и срок бана/голосового мута **1–1440 минут**. Для мута нужен Plasmo Voice.

Голосовать может любой вошедший игрок, включая подключившихся после начала; цель голосования голосовать не может. Один игрок — один голос, выбор можно изменить до завершения.

Нужно не менее **2/3 голосов «за» среди проголосовавших** и одновременно **не менее половины числа допущенных игроков на старте** (без цели). Этот порог не меняется при входах и выходах. Длительность, минимальный онлайн, время игры инициатора и паузы задаются сервером.

OP, `anthub.admin` и игроки с `anthub.vote.protected` защищены от таких голосований. Для прав LuckPerms включите интеграцию. Пример:

```text
/lp group moderator permission set anthub.vote.protected true
```

<a id="auth"></a>

## 🔐 Регистрация и вход

| `[auth] mode` | Способ входа                                                  |
| :------------ | :------------------------------------------------------------ |
| `"false"`     | Auth выключен; действуют правила Minecraft.                   |
| `"base"`      | Пароль аккаунта на сервере.                                   |
| `"hybrid"`    | Пароль и возможность привязать официальный Minecraft-аккаунт. |

`allowRegistration` разрешает регистрацию; `minimumPasswordLength` задаёт минимум **нового** пароля: 6–128 символов, по умолчанию 6. Старые пароли продолжают работать.

`online-mode` в `server.properties` настраивается отдельно: для игроков без официального аккаунта нужен `false`; при `true` Minecraft сначала проверяет официальный аккаунт.

Вход проходит до загрузки мира. Смена пароля, привязка аккаунта и отзыв сохранённых устройств — в **«Безопасности аккаунта»**. Пароли хранятся как хеши Argon2id; при включённом Auth игровой TCP-трафик защищён TLS 1.3.

### Восстановление доступа

1. Убедитесь, что обращается владелец аккаунта.
2. Выполните в консоли `ah auth reset PlayerName`.
3. Скопируйте код из ответа консоли и передайте владельцу лично. При сбросе из игры код видит только запросивший администратор — в окне с кнопкой копирования.
4. Игрок вводит код и новый пароль в форме восстановления.

Код одноразовый, действует **15 минут**; новый отменяет предыдущий. В PostgreSQL хранится только хеш и срок действия, автор выдачи — в журнале без кода. Файлы не создаются. Ответ консоли может сохраняться в её логах. Сброс отзывает устройства и сеансы, удаляет официальную привязку. В игре для сброса нужны вход через Auth и отдельное право `anthub.auth.reset`; OP и `anthub.admin` его не заменяют.

## ⌨️ Команды и права

Игрок указывается ником или серверным UUID; при неоднозначном имени нужен UUID.

| Команда                                             | Действие                                                 |
| :-------------------------------------------------- | :------------------------------------------------------- |
| `/ah`                                               | Открыть меню.                                            |
| `/ah status`                                        | Состояние AntHub, БД, Auth и интеграций.                 |
| `/ah project status`                                | Сборка сервера и последняя проверка.                     |
| `/ah player info <игрок>`                           | UUID, статус и статистика.                               |
| `/ah reports`                                       | Последние пять обращений; ответы — в меню.               |
| `/ah announce <текст>`                              | Разовое объявление.                                      |
| `/ah announce pin <минуты> <текст>`                 | Закрепить сообщение на 1–10080 минут.                    |
| `/ah announce unpin`                                | Убрать закрепление.                                      |
| `/ah maintenance on <минуты> <причина>`             | Ограничить новые входы на 0–1440 минут; `0` — бессрочно. |
| `/ah maintenance off`                               | Выключить обслуживание.                                  |
| `/ah restart <секунды> <причина>`                   | Сохранить мир и остановить сервер через 1–86400 секунд.  |
| `/ah restart cancel`                                | Отменить запланированную остановку.                      |
| `/ah auth reset <игрок>`                            | Выдать приглашение на восстановление.                    |
| `ah auth reserve <игрок>`                           | Закрепить свободное имя; только консоль.                 |
| `ah auth block <игрок>` / `ah auth unblock <игрок>` | Заблокировать / разблокировать аккаунт; только консоль.  |

Обслуживание не отключает уже вошедших игроков, администраторы могут подключаться. **Повторный запуск после `/ah restart` выполняет сервер или другая панель управления сервером** — включите автоматический перезапуск.

### Исправление статистики

Работает для существующих игроков в сети и вне сети. Изменения записываются в журнал.

```text
/ah stats show Player
/ah stats time set Player 120h30m
/ah stats time add Player 5h
/ah stats time subtract Player 30m
/ah stats since set Player 2026-09-01
/ah stats deaths set Player 12
```

Время — целые часы `h` и минуты `m`, итог неотрицательный. Дата — `YYYY-MM-DD` по времени сервера, не в будущем. Дата и время игры меняются независимо; текущая сессия учитывается, дальнейшая игра начисляется к новому итогу. Общее время влияет на допуск к голосованиям о наказаниях.

### LuckPerms

OP уровня 2 и `anthub.admin` дают административный доступ. Для отдельных функций выдавайте права при включённой интеграции:

| Право                                     | Доступ                                            |
| :---------------------------------------- | :------------------------------------------------ |
| `anthub.stats.view` / `anthub.stats.edit` | Просмотр / изменение статистики командами.        |
| `anthub.announce`                         | Объявления и закрепление.                         |
| `anthub.maintenance` / `anthub.restart`   | Обслуживание / остановка.                         |
| `anthub.reports`                          | Обращения, ответы и закрытие.                     |
| `anthub.diagnostics`                      | Состояние AntHub и проекта.                       |
| `anthub.events`                           | Управление событиями.                             |
| `anthub.auth.reset`                       | Восстановление Auth; отдельное право даже для OP. |
| `anthub.vote.protected`                   | Защита от голосований о наказании.                |

Пример: `/lp group moderator permission set anthub.reports true`. Меню и команды проверяют права на сервере; `anthub.admin` также открывает журнал и экспорт.

## 🔄 Обновление

Версия мода — **A.B.C**: **A** меняет совместимость клиент–сервер, **B** добавляет совместимые возможности, **C** исправляет ошибки. Семя указывает ветку `A.x`. Разные версии одной A совместимы; для новых функций может потребоваться обновить обе стороны.

- **Клиент:** выберите версию в списке над кнопкой AntHub, установите и перезапустите игру. Новая версия отмечается рядом со списком.
- **Сервер:** остановите его, замените старый JAR в `mods` новым и запустите. При наличии обновления AntHub пишет WARN в консоль.
- **Перед обновлением:** сохраните резервную копию PostgreSQL, `config/anthub-server.toml` и папки `anthub/`. Не удаляйте `anthub/auth-identity.p12` и не меняйте режим Auth без необходимости.
- **Семя:** меняйте шаблон только по примечаниям к выпуску. При переходе на другую A обновите сервер и `anthubVersion`, затем выпустите новую версию сборки.
