# AntHub → Rivet

AntHub продолжает развитие под названием **[Rivet](https://github.com/abrosdaniel/rivet)**. Новые функции и обновления публикуются в репозитории Rivet.

## Автоматический переход клиента

**AntHub 3.9.0** — небольшой переходный установщик для Minecraft 1.21.1 и NeoForge 21.1.250–21.1.x, Java 21.

1. Установите переходный JAR из [последнего выпуска](https://github.com/abrosdaniel/anthub/releases/latest) вместо прежнего AntHub или обновитесь через его встроенный обновлятор.
2. Запустите игру: установщик загрузит последний совместимый стабильный Rivet и проверит целостность файла.
3. После сообщения о готовности полностью закройте Minecraft и запустите его снова через лаунчер.

Установщик заменит AntHub на Rivet после завершения игры. Клиентские данные переносятся, исходная папка `anthub/` сохраняется. Резервная копия переходного JAR и журнал доступны в `anthub/rivet-migration/`.

При ошибке загрузки или конфликтующих файлах установщик покажет причину; исходный мод сохраняется. Если Rivet уже установлен или существует папка `rivet/`, автоматический переход блокируется, чтобы не перезаписать данные.

## Серверы

Автоматический переход предназначен только для клиентов. На выделенном сервере этот выпуск останавливает запуск с сообщением о ручной миграции. Установите серверный Rivet и перенесите настройки и схему базы данных отдельно. Установщик не изменяет PostgreSQL, серверные настройки и миры.

## Исходный код и сборка

[Описание переходного установщика и команды сборки](anthub/bridge/README.md). Прежние модули AntHub сохранены для истории и сопровождения; текущий CI выпускает только переходный установщик. Для актуального мода и настройки семени используйте [Rivet](https://github.com/abrosdaniel/rivet).
