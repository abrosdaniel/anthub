## 🧩 Модули

| Модуль           | Возможности                                                                                     |
| :--------------- | :---------------------------------------------------------------------------------------------- |
| 📦 **Assembler** | Установка и обновление компонентов, проверка SHA-256.                                           |
| 🏠 **Social**    | Профиль, игроки, новости, правила, объявления, объединения, события, голосования и предложения. |
| 🛡️ **Mod**       | Модерация игроков, обращения, объявления, обслуживание, перезапуск и журнал действий.           |
| 🔐 **Auth**      | Регистрация, вход, привязка Minecraft-аккаунта, смена пароля и управление устройствами.         |
| 🔄 **Updater**   | Самообновление AntHub из официальных GitHub Releases.                                           |

> [!WARNING]
> **LuckPerms** - права, группы и оформление имён;<br>
> **Plasmo Voice** — инструменты голосовой модерации.
> **Xaero's** — инструменты для работы с картой/навигацией.

### Меню сервера

Слева — список, справа — выбранная запись. На небольшом экране подробности открываются отдельно; поиск и место в списке сохраняются. Доступны фильтры **Все / Мои / Участвую**, архив и удалённые записи.

- **Объединения:** обзор, участники, заявки и приглашения. Владелец назначает помощников и может передать руководство.
- **Записи:** основные действия — в карточке, редактирование и удаление — в меню **⋯**.
- **Отмена:** можно отозвать свой отклик или заявку; управляющие могут отменить приглашение. Отмена принятого отклика требует подтверждения и уведомляет автора.
- **Удаление:** автор или текущий владелец и администратор. Восстановление доступно 30 дней.

Помощник управляет набором, заявками, приглашениями и координатами объединения, но не редактирует его название и описание, не удаляет его и не передаёт руководство. Голосование нельзя редактировать после первого голоса.

> [!NOTE]
> Менеджер сборок работает без AntHub на сервере. Серверное меню и Auth требуют установки мода на обе стороны.

<a id="seed"></a>

## 🌱 Семя

**Семя** — публичный GitHub-репозиторий с названием, адресом и клиентской сборкой вашего сервера. Один репозиторий — один сервер.

Скачайте `template.zip`, перенесите его содержимое в свой репозиторий и заполните `anthub.json`. GitHub Actions проверит файлы и опубликует сборку. Сайт, ключи подписи и вручную созданные secrets не нужны.

Пошаговая инструкция по созданию семени есть внутри шаблона.

> [!TIP]
> При обновлении AntHub проверяйте примечания к релизу: шаблон тоже может измениться.

<a id="setup"></a>

## 🛠️ Установка

### Игроку

1. Подготовьте Minecraft **1.21.1**, NeoForge **21.1.250** и Java **21**.
2. Скачайте JAR AntHub из [релизов](https://github.com/abrosdaniel/anthub/releases) и поместите в `mods`.
3. Запустите игру.

### Владельцу сервера

Для распространения клиентской сборки достаточно семени. Для серверных функций:

1. Установите тот же JAR в `mods` сервера.
2. Подготовьте PostgreSQL и файл подключения по инструкции ниже.
3. Настройте [Auth](AUTH.md), если нужна регистрация и вход.
4. При необходимости установите Моды из интеграции, чтобы получить большую совместимость.
5. Запустите сервер и подключитесь клиентом с той же версией AntHub.

<a id="postgresql"></a>

### PostgreSQL

Создайте базу и пользователя для AntHub. Пользователю нужны права на подключение и создание таблиц в схеме `anthub`. Например, администратор базы может выполнить внутри созданной базы:

```sql
CREATE ROLE anthub LOGIN NOSUPERUSER NOCREATEDB NOCREATEROLE NOREPLICATION;
\password anthub
GRANT CONNECT ON DATABASE anthub TO anthub;
CREATE SCHEMA anthub AUTHORIZATION anthub;
```

Команда `\password` запросит пароль дважды. На сервере в `config/anthub-database.properties` укажите:

```properties
host=ИМЯ_ХОСТА
port=ПОРТ_ХОСТА
database=anthub
username=anthub
password=ПАРОЛЬ_ПОЛЬЗОВАТЕЛЯ
passwordEnvironment=
passwordFile=
poolSize=8
sslMode=disable
sslRootCert=
```

Пароль в `.properties` указывается **без кавычек**. Вместо хранения пароля здесь можно задать `passwordEnvironment=ANTHUB_DB_PASSWORD` и передать переменную окружения серверу.

`sslMode=disable` подходит для доверенной внутренней сети. Для подключения через внешнюю сеть используйте `sslMode=verify-full` и укажите путь к корневому сертификату в `sslRootCert`. В Docker контейнер Minecraft должен иметь доступ к сети базы; публиковать порт PostgreSQL в интернет не требуется.

> [!IMPORTANT]
> PostgreSQL обязательна для серверных функций, даже при выключенном Auth. Без подключения сервер остановит запуск с объяснением в консоли. Данные AntHub сохраняются при смене мира.

<a id="connect"></a>

## 🌐 Подключение

1. На главном экране нажмите **AntHub**.
2. Вставьте ссылку на GitHub-репозиторий семени или выберите из каталога.
3. Выберите компоненты и установите сборку.
4. Если AntHub запросит перезапуск, перезапустите игру.
5. Нажмите **«Подключиться»**.

При включённом Auth регистрация или вход появятся до загрузки мира. На сервере без AntHub серверное меню недоступно.
