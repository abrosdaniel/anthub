## AntHub 1.0.0-rc.5

Кандидат в первый релиз для Minecraft 1.21.1, NeoForge 21.1.250 и Java 21.

### Клиент

- Проекты из публичных GitHub-репозиториев: один проект — один сервер.
- Установка выбранных компонентов, проверка SHA-256, запасные ссылки загрузки, кэш, восстановление и откат.
- Обновление названия и адреса проекта при запуске, перед подключением и вручную.
- Новости и правила с прокруткой, управление интерфейсом с клавиатуры.
- Самообновление AntHub из официальных GitHub Releases.

### Сервер

- Меню на F8 с переназначением клавиши; без AntHub на сервере оно отключено.
- Профиль на главной, список игроков и инструменты модерации с проверкой прав.
- Доска объявлений, объединения, события, голосования, предложения и уведомления.
- Интеграции LuckPerms и Plasmo Voice.
- AntHub Auth: режимы false/base/hybrid, смена пароля, сохранённые устройства и отзыв доступа.
- Серверные данные в PostgreSQL. При ошибке подключения запуск останавливается с сообщением в консоли.

### Исправления интерфейса

- Исправлена обработка числовых данных профиля, вызывавшая падение клиента.
- Префиксы и суффиксы поддерживают legacy-форматирование и HEX-теги вида <#FF5555>.
- Профиль перенесён в боковую карточку главной страницы, разделы получили отдельное оформление.
- Убрано отдельное подтверждение при первом подключении Auth; сохранённый ключ сервера проверяется при следующих входах.

### Установка

Установите JAR в папку `mods` клиента. Для серверных функций установите тот же JAR на сервер и настройте PostgreSQL по README. Обновите обе стороны для новых данных серверного меню.

Авторам проектов: распакуйте `template.zip` целиком, включая `.github`, в свой репозиторий. Заполните `anthub.json`; push с новой версией запускает публикацию. SHA-256 вычисляются автоматически, ключи подписи не нужны.

### Перед стабильным выпуском

Это предварительный выпуск. Требуется финальная проверка интерфейса, регистрации/входа, установки сборки и самообновления в настоящей игре, включая Windows и Linux. Автоматические тесты не заменяют эту проверку.

### Авторизация в rc.5

- Единый серверный аккаунт с паролем в режимах base и hybrid. Наличие такого же ника у Mojang не мешает регистрации.
- В hybrid официальный Minecraft-аккаунт можно привязать и отвязать в безопасности аккаунта с подтверждением паролем. Привязка дополнительно проверяется сервисом сессий Minecraft.
- Серверный UUID сохраняется при смене регистра ника и способа входа. Официальный UUID хранится отдельно.
- Сброс пароля отзывает устройства, сеансы и официальную привязку.
- Минимум нового пароля задаётся в anthub-auth.toml: minimumPasswordLength = 6 по умолчанию.
- «Отключиться» завершает вход и возвращает к списку серверов.

Протокол Auth обновлён: установите rc.5 и на сервер, и на клиенты. При выключении Auth применяются обычные UUID Minecraft; автоматический перенос игровых данных между этими режимами не выполняется.

### Исправления rc.5

- Новые аккаунты закрепляют исходный UUID Minecraft. Для установки этой предварительной версии очистите прежние тестовые данные Auth и зарегистрируйтесь заново; перенос аккаунтов не предусмотрен.
- На offline-сервере до регистрации используйте исходный регистр ника, включая команду добавления в whitelist.
- Единое форматирование префиксов и суффиксов в профиле, списке игроков и окне действий. Для игроков в сети метаданные передаются из LuckPerms.
- Компактные карточки игроков со статусом, выделением выбранного игрока и фокусом клавиатуры.
- Боковое меню получило контрастный активный раздел и более спокойное оформление.
