# AntHub 3.5.0

- Семя принимает требования `3.x.x`, `3.4.x` и `3.4.2`: ветку совместимости либо минимальную версию в её пределах.
- Единая проверка применяется при подключении клиента, запуске сервера и выборе обновления AntHub.
- Некорректный формат требования сопровождается подсказкой с допустимыми примерами.
- Формат `A.x` и совместимость клиент–сервер ветки 3 сохранены. Для чтения новых форматов обновите клиент и сервер до 3.5.0; шаблон по умолчанию остаётся с `3.x`.

# AntHub 3.4.0

- Порядок сохранённых скинов меняется кнопками вверх и вниз и сохраняется на сервере; переименование его не меняет.
- Исправлено падение при выборе количества ресурса: числовые значения корректно открываются в редакторе.
- Всплывающие окна сохраняют родное оформление фоновых кнопок Minecraft.
- Прокрутка учитывает вложенные поля, границы области и нулевые события трекпада.
