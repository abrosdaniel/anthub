## AntHub 2.0.3

- Индикатор новой версии — красная точка с тонкой обводкой `#29033F`.
- При обновлении сборки сохранённый выбор компонентов сверяется с новым манифестом: ставшие обязательными моды и их зависимости автоматически включаются.
- Выбор необязательных компонентов сохраняется; удалённые из сборки компоненты исключаются из выбора.
- Экран проверки установки использует итоговый выбор с обязательными компонентами.
