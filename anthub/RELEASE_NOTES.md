# AntHub 3.2.1

- Возвращена боковая карточка игрока при обычном масштабе интерфейса.
- Формы стали компактнее: связанные поля стоят в ряд, прокрутка учитывает высоту содержимого.
- Ответственный за задачу выбирается через поиск по участникам; приглашённые на событие — из списка игроков.
- Место объединения создаётся на одном экране. Удаление места сохраняется; в предложениях и опросах поле места убрано.
- Исправлены черновики и отправка задач, мест, закрытых событий и торговых объявлений.
