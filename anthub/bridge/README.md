# Переходный установщик AntHub → Rivet

AntHub 3.9.0 автоматически загружает последний опубликованный стабильный Rivet для клиента Minecraft 1.21.1, проверяет файл и предлагает полностью закрыть игру. После завершения процесса отдельный установщик сохраняет резервную копию переходного JAR, переносит клиентские данные и заменяет мод. Следующий запуск загружает Rivet.

Исходная папка `anthub/` сохраняется. Журнал и резервная копия JAR находятся в `anthub/rivet-migration/`. Серверные настройки, PostgreSQL и миры не изменяются. При установленном Rivet, существующей папке `rivet/`, повреждённой загрузке или дубликатах модов переход блокируется с объяснением.

## Сборка

```sh
./gradlew :bridge-bootstrap:build :bridge-helper:test --no-daemon
python anthub/tooling/verify_rivet_target.py
python anthub/tooling/bridge_release.py
```

Готовые файлы: `dist/bridge-3.9.0/`. Для обнаружения выпуска старым обновлятором AntHub вместе с JAR публикуется `core.json`. Переходные файлы собираются отдельно от прежней версии 3.8.1, чтобы не выпустить прежний мод под новым номером.

Основной CI проверяет установщик на Linux, Windows и macOS и публикует новый выпуск из проверенного артефакта после успешных проверок основной ветки. Уже опубликованные выпуски не перезаписываются. Workflow `AntHub to Rivet migration installer` дополнительно позволяет вручную собрать артефакты без публикации.

Перед публикацией 3.9.0 серверы и семена должны быть переведены на Rivet. Этот выпуск не работает как прежний серверный AntHub: на выделенном сервере он прекращает запуск до загрузки мира и сообщает о ручном переходе.
