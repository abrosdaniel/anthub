# AntHub 3.9.0 — переход на Rivet

Последний клиентский выпуск AntHub — лёгкий установщик самостоятельного мода Rivet.

- При открытии игры автоматически загружает последний стабильный Rivet для Minecraft 1.21.1 и установленного NeoForge из официального репозитория `abrosdaniel/rivet`.
- Проверяет размер, SHA-256 и идентификатор мода. При ошибке AntHub остаётся установленным; доступна повторная попытка.
- Просит полностью закрыть Minecraft и запустить игру через лаунчер. После завершения процесса устанавливает Rivet и удаляет переходный JAR AntHub из `mods`.
- Сохраняет список серверов, настройки интерфейса и HUD, сохранённые устройства, черновики, выбор компонентов и учёт установленных файлов. Старый lock семени не переносится как действующий: после запуска Rivet нужно получить новый выпуск семени.
- Прежняя папка `anthub` сохраняется. Резервная копия переходного JAR и журнал установщика находятся в `anthub/rivet-migration/`.
- После прерванной замены следующий запуск переходного JAR пытается завершить установку и просит повторный запуск.

## Серверы

Этот выпуск предназначен только для клиентов. На выделенном сервере он останавливает запуск до загрузки мира и сообщает о ручном переходе. PostgreSQL, серверные настройки, права и таблички автоматически не изменяются.

Сначала подготовьте сервер и новый выпуск семени для Rivet, затем предлагайте игрокам переход. Для меню и Auth нужен Rivet на обеих сторонах.
